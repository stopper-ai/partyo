# PARTYO

PARTYO is the party planning, invitation and RSVP product developed in this project.

## Current repository snapshot

This repository starts from the working PARTYO preview preserved in the ChatGPT project workspace.

Core product direction:
- party creation
- invitation builder
- RSVP
- party content and themes
- music and video
- decorations and printable kits
- party mode
- photos, memories and thank-you flow
- admin / studio workflows

## Collaboration

Use feature branches and pull requests for team development.

Suggested branch naming:
- feature/<name>
- fix/<name>
- design/<name>

Do not commit secrets or API keys. Use environment variables for external services.
